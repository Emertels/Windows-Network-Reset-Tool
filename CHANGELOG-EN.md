# Changelog

## 1.0.0 — 2026-10-09

- Updates the run instructions to point directly to the correct project entry point.

- Fixes accented text in CMD by setting console output encoding without using CHCP.

- Combines DNS flush, DHCP renewal, and Winsock/TCP-IP resets in a one-click workflow.
- Displays session date/time and detected language in ten languages.
- Elevates for network operations that require administrator rights.
- Consolidates the utility into one Batch file with ten-language UI and no `chcp 65001` command.


- Corrects accents and cedilla in interface text and documentation, aligns session headers, and updates agent instructions.

- Usage, dependency, and required-file documentation was reviewed to match current project behavior.
